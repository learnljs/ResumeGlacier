# 招聘中心 · 04 简历复用评估

> 「简历复用评估」用于将已有简历库按新的职位进行批量复用评估（跨职位挑人）。

## 一、操作流程

1. **选择目标岗位（必选）**。若该岗位未配置默认初筛模型，页面会红字提示「未配置，无法发起评估」
2. **设置筛选条件（均为选填）**：

| 条件 | 选项 |
|------|------|
| 投递岗位 | 多选，自动过滤为同部门其他未选岗位 |
| 最低学历 | 不限 / 大专 / 本科 / 硕士 / 博士 |
| 院校档次 | 不限 / 985 / 211 / 海归 |
| 英语等级 | 不限 / 四级 / 六级 / 专四 / 专八 |
| 最低工作年限 | 不限 / 1 / 3 / 5 / 10 年 |
| 毕业年限 | 数字区间 |
| 专业要求 | 多个专业用逗号分隔，如「计算机科学,软件工程」 |

3. 点击「**刷新候选人列表**」，从候选人池中筛选出符合条件的候选人
4. 勾选候选人，点击「**发起 AI 评估(N)**」，页面显示评估进度条（评估中 N%）
5. 评估完成后，对已评估的候选人可点击「跟进」或勾选后「批量跟进(N)」（未评估的候选人跟进按钮为禁用状态，提示「评估完成后可跟进」）

## 二、表格列说明

| 列 | 说明 |
|----|------|
| 候选人 | 姓名、性别、已评估徽章、学校·毕业时间文案（如「应届 / 毕业N年 / 在读」） |
| 投递岗位 | 原投递岗位 |
| 接收时间 | 简历收取时间 |
| 学历 | 学历信息 |
| 专业 | 专业信息 |
| 知识（5星） | 知识维度评分 |
| 技能（5星） | 技能维度评分 |
| 初筛得分 | 按新职位评估的得分 |
| 跟进 | 跟进操作按钮 |

## 三、便利功能

- 离开页面后重新返回，**筛选条件、评估批次与滚动位置会自动恢复**，并继续轮询评估进度（每 2 秒一次），完成后提示「评估全部完成」
- 支持 **Shift + 点击**仅选择当前页候选人
