## 一、筛选条件

- **关键词**：姓名 / 邮箱 / 电话
- **职位**：多选
- **来源**：下拉选择
- **多级排序**：可叠加多个排序条件

## 二、表格列说明

| 列 | 说明 |
|----|------|
| **候选人** | 姓名（可复制）、职位（未分配显示灰字） |
| **来源** | 简历渠道 |
| **知识 / 技能** | 星级评分，可直接点击星形修改分数 |
| **初筛得分** | 四色标：≥80 绿 / ≥60 蓝 / ≥40 黄 / <40 红 |
| **评估日期 / 接收时间** | 评估与收取时间 |

## 三、常用操作

| 操作 | 说明 |
|------|------|
| **查看** | 进入简历详情页 |
| **跟进** | 弹出「跟进标记」窗口——选择关联岗位（多岗位时下拉，显示各岗位得分与是否已跟进）、按分类选择标签（硬性标签 / 意向判断 / 自定义，也可新建标签并选择颜色）、填写备注，确认后完成跟进 |
| **不合适** | 弹出窗口填写原因（提供常用预设），确认后该行从列表消失 |
| **批量跟进** | 勾选多人后点击「批量跟进(N)」，统一打标签并确认；已存在跟进记录的候选人会自动跳过 |

**空状态提示**：页面无数据时显示「暂无已筛选简历——简历完成AI筛选后将显示在这里」。
