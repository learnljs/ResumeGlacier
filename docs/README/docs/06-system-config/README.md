# 六、系统配置（组内总览）

> 「系统配置」包含 8 个子页面，用于系统初始化与参数维护。顶部副标题「管理邮箱收取、AI模型、简历来源和职位信息」，子导航标签为：邮箱配置、AI模型、简历来源、职位管理、提示词管理、跟进标签、企微同步、数据模块。

[← 返回教程目录](../../README.md)

---

## 页面分工

| 子页面 | 用途 | 入口 |
|--------|------|------|
| **邮箱配置** | 管理多个 IMAP 邮箱，自动收取不同渠道的简历邮件 | [01 · 邮箱配置](./01-email-config.md) |
| **AI 模型** | 管理多个 AI 模型，用于简历智能筛选 | [02 · AI 模型](./02-ai-models.md) |
| **简历来源** | 管理简历来源渠道，并配置各渠道的解析规则 | [03 · 简历来源](./03-resume-sources.md) |
| **职位管理** | 管理招聘职位，配置每个职位的权重模型与评估提示词 | [04 · 职位管理](./04-position-management.md) |
| **提示词管理（高级）** | 按职位独立维护 AI 评估提示词，支持版本管理与回滚 | [05 · 提示词管理](./05-prompt-management.md) |
| **跟进标签** | 管理跟进标签的分类与自定义标签 | [06 · 跟进标签](./06-follow-up-tags.md) |
| **企微同步** | 配置企业微信智能表格同步 | [07 · 企微同步](./07-wecom-sync.md) |
| **数据模块（技术 / 管理员使用）** | 面向技术人员的数据库查询工具（仅支持 SELECT，只读） | [08 · 数据模块](./08-data-module.md) |

## 推荐配置顺序

系统初始化建议按以下顺序完成：

```
01 邮箱配置 → 02 AI 模型 → 04 职位管理 → 05 提示词管理
     ↓              ↓            ↓            ↓
（可选）03 简历来源 · 06 跟进标签 · 07 企微同步 · 08 数据模块
```

| 步骤 | 做什么 | 对应子页 |
|------|--------|----------|
| 1 | 接入收件邮箱并测试连接 | 邮箱配置 |
| 2 | 添加 AI 模型并设为默认 | AI 模型 |
| 3 | 创建招聘职位（权重模型 + 提示词） | 职位管理、提示词管理 |
| 4 | （可选）配置简历来源渠道规则 | 简历来源 |
| 5 | （可选）配置企微同步 Webhook 与字段映射 | 企微同步 |
