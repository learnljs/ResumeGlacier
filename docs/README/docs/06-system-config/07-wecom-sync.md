## 一、Webhook 地址区

- 输入 Webhook URL 并保存、测试连接
- 已保存地址会脱敏展示（仅显示 key 后 4 位），修改需重新输入完整 URL
- 测试连接会发送一条空值记录，需在企微端手动删除

## 二、字段映射区

- 「导入示例 JSON」「新增映射」按钮
- 编辑表单：

| 字段 | 说明 |
|------|------|
| HR 系统字段 | 必填，下拉选择 |
| 企微字段 ID | 必填 |
| 企微字段名称 | 必填 |
| 企微字段类型 | 必填 |
| 转换方式 | 5 种：DIRECT 直接 / ENUM_MAP 枚举映射 / TIMESTAMP 时间戳 / CONCAT 拼接 / FIXED 固定值；枚举时可「填入默认值」 |
| 转换参数 | JSON |

- 列表每行显示「HR字段 → 转换方式 → 企微字段 + 类型」，可禁用

## 三、职位映射区

- 为每个启用中的职位填写企微「岗位管理」表的 record_id（用于同步「应聘岗位」字段），保存生效

## 注意事项

- 导入企微表格 schema 时，单 / 多选选项一并导入
- 公式、自动编号、文件等不支持的字段会跳过
