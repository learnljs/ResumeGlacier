# 系统配置 · 05 提示词管理（高级）

> 用途：按职位独立维护 AI 评估提示词，保存即生效。页面顶部为搜索框；职位行显示当前版本号（未配置时显示警示）与历史版本数。

## 一、编辑区（每个职位展开后有 4 个编辑区）

| 编辑区 | 说明 |
|--------|------|
| **提示词主体** | AI 角色定义、核心任务、JD 解读规则。必须包含且仅包含一个 `{{resumeText}}` 占位符 |
| **知识维度** | 知识维度评分规则，语法：`### 评分规则` → `### 方向名` → `1.1 问题文本` → 缩进行「评判标准：xxx」 |
| **技能维度** | 技能维度评分规则，语法同上 |
| **通用评分规则** | 如何综合两个维度得分得出最终星级的规则文本，AI 严格按此打分 |

## 二、底部操作区

| 操作 | 说明 |
|------|------|
| 保存人 | 选填 |
| 修改说明 | 选填 |
| **预览校验** | 选择一份该职位的简历作为校验样本，真实运行一次 AI 评估，展示初筛总分、各维度星 × 权重得分、AI 评分依据与原始 JSON 数据 |
| **保存为新版本** | 生成新版本号，保存后立即生效，只影响之后的新评估，不影响已有评估结果 |

## 三、版本历史弹窗

- **版本列表**：版本号、当前标记、时间、保存人、修改说明
- **每条可操作**：「查看」完整内容，非当前版本可「回滚」（确认后立即生效）与「删除」
- **「版本对比」**：选择两个版本对比，差异行以绿色（新增）/ 红色（删除）高亮

## 四、注意事项

- 未保存的修改在切换职位或收起弹窗时会弹出「放弃未保存的修改？」确认框；切换职位会丢弃未保存修改
- **提示词保存即生效，版本可回滚可删除**
