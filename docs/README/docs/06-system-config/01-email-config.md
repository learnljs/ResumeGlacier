# 系统配置 · 01 邮箱配置

> 用途：管理多个 IMAP 邮箱，自动收取不同渠道的简历邮件。

## 一、新增 / 编辑邮箱表单字段

| 字段 | 说明 |
|------|------|
| 邮箱别名 | 选填，便于区分 |
| 关联简历来源 | 下拉选择，可不关联 |
| 邮箱服务商 | 企业微信邮箱 / QQ 邮箱 / 163 邮箱 / 126 邮箱 / Gmail / Outlook / 自定义；点选自动填充服务器与端口 |
| IMAP 服务器 | 选填（自定义时填写） |
| 端口 | 数字，默认 993 |
| 启用 SSL/TLS | 勾选启用 |
| 邮箱地址 | 必填 |
| 密码 | 必填；编辑时留空则不修改 |
| 收取文件夹 | 默认 INBOX，可点击「获取文件夹」自动拉取后下拉选择 |

## 二、操作

- **表单操作**：测试连接、保存、取消
- **列表操作**：启用 / 禁用、编辑、删除
- **邮箱列表展示**：别名、启用状态、邮箱地址、服务器:端口、关联来源、邮件数、简历数、上次收取时间

## 三、配置帮助（常用邮箱的注意事项）

| 邮箱 | 注意事项 |
|------|----------|
| **企业微信邮箱** | 需开启 IMAP，并使用客户端专用密码 |
| **QQ / 163 邮箱** | 使用「授权码」而非登录密码 |
| **Gmail** | 需开启两步验证并使用应用专用密码 |

所有邮箱密码均加密存储（AES-256-GCM），界面不回显。
