## 一、配置字段

| 字段 | 说明 |
|------|------|
| **来源名称**（必填） | 如前程无忧、BOSS直聘、猎聘 |
| **描述**（选填） | 渠道说明 |
| **邮件主题解析规则** | 正则表达式，首个捕获组为候选人姓名（页面附示例） |
| **AI 解析提示词模板**（选填） | 筛选时作为额外上下文 |

## 二、列表展示

- 名称、启用状态、描述、简历数、关联邮箱数、「已配置提示词」「主题解析」徽章
- 可编辑、删除
