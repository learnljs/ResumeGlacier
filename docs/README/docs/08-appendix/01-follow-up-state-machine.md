## 状态流转速查

| 当前状态 | 正向流转（必填字段） | 可回退到 |
|----------|----------------------|----------|
| 沟通中 | 待面试（面试时间）、不合适（原因） | — |
| 待面试 | 已面试、取消面试（原因） | 沟通中 |
| 已面试 | 已发offer（入职时间）、不合适（原因） | 待面试 |
| 已发offer | 待入职（入职时间）、拒offer（原因） | 已面试 |
| 待入职 | 已入职（入职时间）、拒offer（原因） | 已发offer |
| 已入职 | 已离职（离职日期 + 原因） | 待入职 |
| 已离职 | — | 已入职 |
| 拒offer | — | 待入职、已发offer |
| 取消面试 | — | 待面试 |
| 不合适 | — | 已面试、沟通中 |

## 流转图（正向主线）

```
沟通中 → 待面试 → 已面试 → 已发offer → 待入职 → 已入职 → 已离职
   │       │        │         │          │
   └→不合适 └→取消面试 └→不合适  └→拒offer  └→拒offer
```

## 要点

- 所有正向流转按必填字段校验（面试时间、原因、入职时间、离职日期 + 原因等）
- 回退操作均需填写回退原因，写入审计日志
- 已离职 / 拒offer / 取消面试 / 不合适 为终点状态，仅支持回退
- 每日 02:00 系统自动扫描当日到期离职记录，自动转「已离职」并触发企微同步
