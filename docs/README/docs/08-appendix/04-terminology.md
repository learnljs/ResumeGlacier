# 附录 D · 常用术语对照

> 系统核心术语速查表。遇到不熟悉的说法时可在此对照。

[← 返回教程目录](../../README.md) | [上一篇：附录 C ←](./03-resume-status-flow.md)

---

| 术语 | 说明 |
|------|------|
| **初筛得分 / 初始分** | AI 按职位提示词对知识、技能维度评估得出的加权分数（0-100） |
| **冰山模型** | 基于 6 维度的综合评估体系 |
| **职位权重模型** | 每个职位独立配置的评分权重（初筛 / 冰山两组） |
| **提示词** | 按职位配置的 AI 评估规则文本，保存即生效 |
| **跟进状态机** | 沟通中 → … → 已入职（或淘汰）的 10 状态流转规则 |
| **企微智能表格** | 企业微信的在线表格，用于同步跟进数据 |
| **曝光卡** | Boss 直聘曝光刷新卡，用于提升职位曝光 |
| **候选人池** | 全部简历库，支持跨职位筛选复用评估 |
| **任务批次** | 一次邮件收取或简历处理任务的编号（YYYYMMDD-NNN） |
