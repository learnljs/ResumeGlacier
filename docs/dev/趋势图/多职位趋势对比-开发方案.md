# 数据概览 · 多职位趋势对比 — 开发文档

> 基于现有「岗位趋势」单职位折线图，新增多职位选择与对比功能，支持 2-5 个职位在同一条折线图上对比趋势变化。

---

## 1. 功能规格

### 1.1 概述

当前仪表盘「岗位趋势」区域（`PositionTrendChart`）仅支持单选一个职位查看趋势折线图。本次改造将其替换为 `PositionTrendCompareChart`，支持：

- **多职位选择**：通过 `MultiSelect` 组件同时选择 1-5 个职位（上限 5）
- **趋势对比**：多条折线在同一图表中渲染，不同颜色区分
- **图例交互**：自定义图例标签，点击可切换线条显隐
- **自定义 Tooltip**：顶部日期 + 各职位简历数（固定顺序）

### 1.2 用户故事

| # | 作为 | 我想要 | 以便 |
|---|------|--------|------|
| US1 | HR | 同时查看 2-5 个职位的收取趋势 | 对比不同岗位的简历增长情况 |
| US2 | HR | 点击图例切换某个职位的显隐 | 聚焦关注特定职位的趋势 |
| US3 | HR | Hover 图表时看到该日期各职位的具体数值 | 精确了解某天的数据差异 |
| US4 | HR | 在不同粒度和时间范围下对比 | 灵活切换统计维度 |

### 1.3 职位选择行为

| 操作 | 行为 |
|------|------|
| 首次加载 | 默认选中第一个职位（单条线） |
| 添加职位 | 通过 MultiSelect 点击添加，图表立即刷新 |
| 移除职位 | 通过 MultiSelect 取消选中或点击 X，或点击图例隐藏 |
| 达到上限（5个） | MultiSelect 剩余选项置灰 |
| 选 1 个时 | 正常显示图例和单条折线（不因数量变化改变布局） |
| 选 0 个时 | 不发起请求，显示"请选择职位查看趋势"引导 |

### 1.4 图例与 Tooltip 交互

| 操作 | 行为 |
|------|------|
| 图例标签 | 彩色圆点 + 职位名，排列在 MultiSelect 右侧 |
| 点击图例 | 切换该职位折线显隐（本地 state 管理 `hiddenIds`） |
| Hover 图表 | 自定义 Tooltip：第一行日期，分隔线，下方各职位名+数值 |
| Tooltip 排序 | 保持职位选择顺序（固定），不按值排序 |
| Tooltip 隐藏 | 被图例隐藏的职位不在 Tooltip 中显示 |

### 1.5 控件行为

与现有逻辑一致：

| 操作 | 行为 |
|------|------|
| 切换粒度 | 时间范围自动跳回该粒度默认值 |
| 切换时间范围 | 图表立即刷新 |
| 添加/移除职位 | 图表立即刷新（保持当前粒度+时间范围） |
| 页面刷新 | 粒度 →「每日」、时间范围→「近一周」、选中→第一个职位 |

### 1.6 边界态

| 状态 | 条件 | UI 表现 |
|------|------|---------|
| 加载中 | API 请求进行中 | 图表区域 Skeleton 占位 |
| 职位列表为空 | `positionStats` 为空数组 | 居中空状态"暂无活跃岗位" |
| 未选择职位 | `selectedIds` 为空数组 | 居中引导文案"请选择职位查看趋势" |
| 暂无数据 | 所有职位在所选时间范围内 count 均为 0 | 居中空状态"暂无趋势数据" |
| 数据点不足 | 数据点 < 2 个 | 保留折线渲染，顶部黄色 banner「数据点较少，建议切换更长时间范围」 |
| 某职位全 0 | 新岗位无简历 | 贴底平直线（正常渲染） |
| 参数非法 | API 参数校验失败 | API 返回 400 + 合法值列表，前端 toast 错误 |

### 1.7 验收标准

- [ ] MultiSelect 可同时选择 1-5 个职位，达到上限后其余选项置灰
- [ ] 默认选中第一个职位，切换粒度后范围回到默认、职位选中不变
- [ ] 多条折线颜色不同，分别对应 `--chart-1` ~ `--chart-5`
- [ ] 自定义图例标签在图表上方，彩色圆点 + 职位名，点击可切换显隐
- [ ] 自定义 Tooltip 显示日期（顶部）和各职位简历数（按固定顺序）
- [ ] 单职位时图例和图表行为正常
- [ ] 全 0 的职位渲染为贴底平直线
- [ ] 粒度切换 + 时间范围切换 + 职位增删均触发图表刷新
- [ ] 加载中 / 空数据 / 数据不足三种边界态正确
- [ ] 移动端 MultiSelect + 图例折行不影响布局
- [ ] 原有单职位 PositionTrendChart 已删除

### 3.1 表结构

**无 schema 变更。** 复用现有 `Resume` 表的 `positionId` + `sourceEmailReceivedAt`/`createdAt` 字段做 count 查询。

### 3.2 查询方式

### 4.3 实现要点

```typescript
// app/api/dashboard/position-trends/batch/route.ts

export async function GET(request: NextRequest) {
  const { searchParams } = new URL(request.url)
  
  // 1. 解析参数
  const positionIdsStr = searchParams.get('positionIds')
  const granularity = searchParams.get('granularity')
  const range = searchParams.get('range')
  
  // 2. 校验 positionIds
  if (!positionIdsStr) {
    return NextResponse.json({ error: '缺少必填参数: positionIds' }, { status: 400 })
  }
  const positionIds = positionIdsStr.split(',').filter(Boolean)
  if (positionIds.length < 2 || positionIds.length > 5) {
    return NextResponse.json({ error: '职位数量必须在 2-5 个之间' }, { status: 400 })
  }
  
  // 3. 校验 granularity
  const validGranularities = ['daily', 'weekly', 'monthly']
  if (!granularity || !validGranularities.includes(granularity)) {
    return NextResponse.json(
      { error: `无效的统计粒度: ${granularity}`, validGranularities },
      { status: 400 }
    )
  }
  
  // 4. 校验 range
  const validRanges = TIME_RANGE_OPTIONS[granularity as TrendGranularity]
  if (!range || !validRanges.includes(range as TimeRange)) {
    return NextResponse.json(
      { error: `无效的时间范围: ${range}`, validRanges },
      { status: 400 }
    )
  }
  
  // 5. 校验岗位存在
  for (const id of positionIds) {
    const position = await prisma.position.findUnique({ where: { id } })
    if (!position) {
      return NextResponse.json({ error: `岗位不存在: ${id}` }, { status: 404 })
    }
  }
  
  // 6. 获取趋势数据
  const result = await getMultiPositionTrendData(
    granularity as TrendGranularity,
    range as TimeRange,
    positionIds
  )
  
  return NextResponse.json(result)
}
```

### 5.4 数据转换

后端返回分列式数据，需要转换为 Recharts 的行式 data 数组：

```typescript
// 输入:
// dates:    [{ label: "7/1" }, { label: "7/2" }]
// series: [
//   { positionName: "前端", data: [5, 8] },
//   { positionName: "后端", data: [3, 6] },
// ]

// 输出 (Recharts data):
// [
//   { label: "7/1", "前端": 5, "后端": 3 },
//   { label: "7/2", "前端": 8, "后端": 6 },
// ]

function transformToChartData(response: MultiPositionTrendResponse) {
  return response.dates.map((d, i) => {
    const row: Record<string, string | number> = { label: d.label }
    response.series.forEach(s => {
      row[s.positionName] = s.data[i]
    })
    return row
  })
}
```

### 6.2 queryMultiPositionTrendCounts 实现细节

```typescript
export async function queryMultiPositionTrendCounts(
  ranges: DateRange[],
  positionIds: string[]
) {
  const result = new Map()

  // 先批量查询所有岗位的信息
  const positions = await prisma.position.findMany({
    where: { id: { in: positionIds } }
  })
  const positionMap = new Map(positions.map(p => [p.id, p]))

  // 对每个职位，并发查询所有 bucket 的 count
  await Promise.all(
    positionIds.map(async (positionId) => {
      const position = positionMap.get(positionId)
      if (!position) return // 不存在则跳过

      const counts = await Promise.all(
        ranges.map(async (range) => {
          const count = await prisma.resume.count({
            where: {
              positionId,
              status: { not: 'UNPARSED' }, // 排除未解析的简历
              AND: [
                // receivedAtWhere(range.start, range.end) 逻辑
                {
                  OR: [
                    {
                      sourceEmailReceivedAt: {
                        gte: range.start,
                        lt: range.end
                      }
                    },
                    {
                      sourceEmailReceivedAt: null,
                      createdAt: {
                        gte: range.start,
                        lt: range.end
                      }
                    }
                  ]
                }
              ]
            }
          })
          return { label: range.label, count }
        })
      )

      result.set(positionId, {
        positionName: position.title,
        counts
      })
    })
  )

  return result
}
```

### 6.3 getMultiPositionTrendData 实现细节

```typescript
export async function getMultiPositionTrendData(
  granularity: TrendGranularity,
  range: TimeRange,
  positionIds: string[]
): Promise<MultiPositionTrendResponse> {
  // 1. 生成日期区间
  const { ranges, truncated } = getDateRanges(granularity, range)

  // 2. 批量查询
  const countsMap = await queryMultiPositionTrendCounts(ranges, positionIds)

  // 3. 组装响应
  const dates = ranges.map(r => ({
    date: r.start.toISOString(),
    label: r.label
  }))

  const series = positionIds
    .filter(id => countsMap.has(id))
    .map(positionId => {
      const info = countsMap.get(positionId)!
      return {
        positionId,
        positionName: info.positionName,
        data: info.counts.map(c => c.count)
      }
    })

  // 4. 生成副标题
  const label = `${GRANULARITY_LABELS[granularity]} · ${TIME_RANGE_LABELS[range]}` +
    (truncated ? `（近 ${SOFT_CAPS[granularity]} ${granularity === 'daily' ? '天' : granularity === 'weekly' ? '周' : '个月'}）` : '')

  return {
    granularity,
    range,
    label,
    truncated,
    dates,
    series
  }
}
```
