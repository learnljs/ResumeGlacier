# S6 — 简历详情页重构 详细规格说明

> **优先级**：P2（评估的核心展示页面）
>
> **依赖**：S1（数据模型重构）、S8（评估维度评分 API）、S3（权重模型管理）
>
> **目标**：将详情页的"AI 分析结果"Tab 改造为"评估结果"Tab，集成雷达图、权重模型选择和得分计算。

---

## 一、功能模块定义

S6 包含以下 4 个模块：

| 模块 | 类型 | 说明 |
|------|------|------|
| Tab 结构调整 | 修改 | 重命名 Tab、移除模型输出 Tab |
| 雷达图组件 | 新建 | 六边形雷达图展示 6 个评估维度 |
| 权重模型选择器 | 新建 | 切换权重模型，实时计算得分 |
| 评分组件 | 新建 | 点击维度弹出评分（星级 + 文本评价） |

### 2.3 职位选择区域

#### 2.3.1 功能说明

const [selectedPositionId, setSelectedPositionId] = useState<string | null>(

### 2.4 雷达图组件

#### 2.4.1 文件位置

创建 `components/resume/evaluation-radar.tsx`

#### 2.4.2 组件接口

```typescript
interface EvaluationRadarProps {
  evaluations: {
    dimension: string
    rating: number | null
    comment: string | null
  }[]
  editableDimensions?: string[]  // 可编辑的维度 key 列表
  onDimensionClick?: (dimension: string) => void
}
```

#### 2.4.3 实现方案

使用 `recharts` 的 `RadarChart` 组件：

```typescript
import { Radar, RadarChart, PolarGrid, PolarAngleAxis, PolarRadiusAxis } from 'recharts'
```

**数据格式**：
```typescript
const data = DIMENSION_KEYS.map((key) => ({
  dimension: EVALUATION_DIMENSIONS[key].label,
  value: evaluations.find((e) => e.dimension === key)?.rating || 0,
  fullMark: 5,
}))
```

**维度顺序**（知识和技能相邻）：
```
知识 → 技能 → 自我认知 → 品质特质 → 价值观 → 动机
```

**样式规则**：
- 已评分维度：实色填充，显示数值
- 未评分维度（rating = null）：灰色虚线，不显示数值
- 可编辑维度：鼠标悬停时显示手型光标
- 只读维度：鼠标悬停时无变化

#### 2.4.4 交互

- 点击维度顶点或标签 → 弹出评分组件
- 只读维度点击无响应
- 评分保存后，雷达图自动刷新

### 2.7 评分权限控制

#### 2.7.1 权限矩阵

通过 URL 参数 `from` 控制：

| from 值 | 可编辑维度 | 只读维度 |
|---------|-----------|---------|
| `screened` | knowledge, skill | selfAwareness, personality, values, motivation |
| `contacting` | knowledge, skill | selfAwareness, personality, values, motivation |
| `interview-scheduled` | 全部 6 个维度 | 无 |
| `interviewed` | 全部 6 个维度 | 无 |
| 无参数（默认） | knowledge, skill | 其余只读 |

#### 2.7.2 实现逻辑

```typescript
const searchParams = useSearchParams()
const from = searchParams.get('from')

const editableDimensions = useMemo(() => {
  switch (from) {
    case 'interview-scheduled':
    case 'interviewed':
      return DIMENSION_KEYS  // 全部可编辑
    case 'screened':
    case 'contacting':
    default:
      return ['knowledge', 'skill']  // 仅知识和技能
  }
}, [from])
```

#### 2.7.3 视觉区分

- 可编辑维度：彩色星级图标，鼠标悬停显示手型光标
- 只读维度：灰色星级图标，鼠标悬停无变化，点击无响应

## 五、非功能需求

### 5.1 性能要求

- 页面加载时间 < 2s（含雷达图渲染）

- 评分保存后雷达图刷新无闪烁

### 5.2 依赖

- `recharts`：雷达图组件（需安装：`yarn add recharts`）
- `react-markdown`：AI 详细分析渲染（已有）

### 5.3 UI/UX 要求

- 使用项目统一的 UI 组件（`@/components/ui/*`）
- 使用 `sonner` toast 显示操作结果
- 雷达图响应式布局，适配不同屏幕宽度
- 评分弹窗居中显示，背景遮罩
