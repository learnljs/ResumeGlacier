# S11 - 跟进管理高级筛选

## 一、概述

在跟进管理页面搜索栏右侧新增「高级筛选」按钮，点击展开下拉面板，暴露已支持的标签、职位、日期范围筛选能力，筛选条件同步 URL。

### 核心变更

| 变更项 | 旧 | 新 |
|-------|---|---|
| 筛选入口 | 仅搜索框 | 搜索框 + 高级筛选按钮 |
| 标签筛选 | API 已支持，UI 未暴露 | 多选下拉 + AND/OR 切换 |
| 职位筛选 | API 已支持，UI 未暴露 | 单选下拉 |
| 日期筛选 | API 已支持，UI 未暴露 | 双日期选择器 |
| 条件可见性 | 无 | 面板底部汇总行 + Badge |

## 二、交互设计

### 2.1 基本交互

```
默认收起:
┌──────────────────────────────────────────────────────────┐
│  [🔍 搜索候选人...          ]  [高级筛选 ▾]               │
└──────────────────────────────────────────────────────────┘

点击展开:
┌──────────────────────────────────────────────────────────┐
│  [🔍 搜索候选人...          ]  [高级筛选 ▾]               │
│──────────────────────────────────────────────────────────│
│  标签: [▼ 选择标签...]       ◎满足任一  ○满足全部        │
│  职位: [▼ 选择职位...]                                  │
│  日期: [____起始____] 至 [____结束____]   [清除筛选]      │
│                                                          │
│  ▸ 已选: [标签A ✕] [前端 ✕] [06-01 ~ 06-15]              │
└──────────────────────────────────────────────────────────┘
```

- 点击「高级筛选」按钮切换面板展开/收起
- 展开时按钮高亮，有激活条件时按钮旁显示数量角标（如「高级筛选 3」）
- 面板用 Popover 方式在搜索栏下方展开，不遮挡表格

### 2.2 各筛选控件

#### 搜索框
- 位置：搜索栏左侧，与现在一致
- 行为：回车触发搜索，同步 `?search=`

#### 标签筛选
- 类型：多选下拉（Checkbox 列表）
- 数据源：`GET /api/follow-up/tags`
- 逻辑切换：Radio ——「满足任一」(OR) /「满足全部」(AND)，默认 OR
- URL：`?tagIds=id1,id2&tagLogic=OR`

#### 职位筛选
- 类型：单选下拉（可搜索）
- 数据源：`GET /api/positions?isActive=true`
- URL：`?positionId=xxx`

#### 日期范围
- 类型：两个 `<input type="date">` 
- 语义：按跟进记录创建时间 (`createdAt`) 筛选
- URL：`?dateFrom=2024-06-01&dateTo=2024-06-15`

### 2.3 已选条件汇总行

展开面板时显示，列出所有当前激活的筛选条件，每个条件可单独删除（点击 ✕）。清除所有用「清除筛选」按钮。

### 2.4 URL 同步

所有筛选条件同步到 URL query string，与现有 Tab、分页参数保持一致：

```
/resume/follow-up?tab=CONTACTING&search=张三&tagIds=a,b&tagLogic=OR&positionId=xxx&dateFrom=2024-06-01&dateTo=2024-06-15&page=1
```

切换 Tab 时不清除筛选条件（保持在同一筛选上下文下切换状态）。

## 四、验收标准

| 检查项 | 标准 |
|-------|------|
| 高级筛选按钮 | 搜索栏右侧可见，点击展开/收起面板 |
| 激活计数 | 有筛选条件激活时按钮显示数量角标 |
| 标签多选 | 可多选标签，OR/AND 切换生效 |
| 职位单选 | 可筛选特定职位 |
| 日期范围 | 起始-结束日期筛选正确 |
| 搜索+筛选联动 | 搜索框和高级筛选同时生效（AND 关系） |
| 已选汇总 | 面板底部显示已选条件 Badge，可单独清除 |
| 清除全部 | 「清除筛选」按钮重置所有条件 |
| URL 同步 | 刷新页面筛选条件保留 |
| Tab 切换 | 切换 Tab 时筛选条件不清除 |
| 空状态 | 无匹配结果时显示空状态提示 |
