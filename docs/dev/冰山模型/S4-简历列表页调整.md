# S4 — 简历列表页调整 详细规格说明

> **优先级**：P3（改动最小，优先级最低）
>
> **依赖**：无
>
> **目标**：移除简历列表中不再适用的按钮和列，简化页面展示。

---

## 一、功能模块定义

S4 仅包含 1 个模块：

| 模块 | 类型 | 说明 |
|------|------|------|
| 列表清理 | 修改 | 移除"解析"按钮、"跟进"按钮、"状态"列 |

---

## 二、详细功能点描述

### 2.1 文件位置

`app/resume/list/page.tsx`

### 2.2 移除项

| 移除项 | 位置 | 原因 |
|--------|------|------|
| "解析"按钮 | 每行操作列 | 简历自动解析，无需手动触发 |
| "跟进"按钮 | 每行操作列 | 简历需先经 AI 评分进入已筛选列表后才能跟进 |
| "状态"列 | 表头 + 每行状态 Badge | PASS/FAIL 概念不再使用 |

### 2.3 保留项

| 保留项 | 说明 |
|--------|------|
| 候选人信息 | 姓名、电话、邮箱 |
| 来源渠道 | resumeSource.name |
| 职位信息 | position.title，含分配下拉框 |
| 投递时间 | createdAt |
| "查看详情"按钮 | 链接到详情页 |
| 批量操作 | 批量匹配职位、批量解析、批量筛选等 |
| 搜索和筛选 | 搜索框、状态筛选、职位筛选等 |

### 2.4 现有代码引用清理

需要删除以下代码引用：

1. **"解析"按钮**：删除 `handleParse` 相关的按钮渲染代码
2. **"跟进"按钮**：删除 `handleFollowUp` 相关的按钮渲染代码和 `FollowUpDialog` 引用
3. **"状态"列**：删除 `<th>状态</th>` 和对应的 `<td>` 渲染代码
4. **statusColors/statusLabels**：如果没有其他地方引用，可以删除这些常量
5. **FollowUpDialog 组件**：如果页面不再使用，删除 import

### 2.5 操作列简化

移除"解析"和"跟进"按钮后，操作列仅保留：

```tsx
<td className="py-3 px-4 text-center">
  <Link href={`/resume/detail/${resume.id}`}>
    <Button variant="ghost" size="sm" className="gap-1 h-7 px-2 text-xs">
      <Eye className="h-3 w-3" />
      查看
    </Button>
  </Link>
</td>
```
