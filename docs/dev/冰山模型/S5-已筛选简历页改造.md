# S5 — 已筛选简历页改造 详细规格说明

> **优先级**：P2（HR 主工作台，业务价值最高）
>
> **依赖**：S1（数据模型重构）、S8（评估维度评分 API）、S3（权重模型管理）
>
> **目标**：将已筛选简历页面改造为显示星级评分和初筛得分，支持内联编辑。

---

## 一、功能模块定义

S5 包含以下 2 个模块：

| 模块 | 类型 | 说明 |
|------|------|------|
| 列表展示改造 | 修改 | 替换 AI 分数为星级评分 + 初筛得分 |
| 内联编辑 | 新建 | 点击星级直接修改，自动重算得分 |

## 二、详细功能点描述

### 2.1 列表展示改造

#### 2.1.1 文件位置

`app/resume/screened/page.tsx`

#### 2.1.2 列字段变更

**现有列** → **改造后列**：

| 现有列 | 改造后 | 说明 |
|--------|--------|------|
| 候选人信息 | 候选人信息 | 不变 |
| 职位 | 职位 | 不变 |
| 来源 | 来源 | 不变 |
| 评分（AI 分数） | **知识维度** | 星级展示（1-5星），可点击编辑 |
| — | **技能维度** | 星级展示（1-5星），可点击编辑 |
| — | **初筛得分** | 百分制（0-100），自动计算 |
| 状态 | — | 移除 |
| 筛选时间 | **评估日期** | 显示 screenedAt（原"筛选时间"改名） |
| — | **接收时间** | 显示 email.receivedAt（新增列） |
| 操作 | 操作 | 不变 |

#### 2.1.3 数据来源变更

**现有 API 调用**：
```
GET /api/resumes?status=SCREENED&followUp=NO
```

**改造后**：API 调用不变，但响应数据需要包含：
- `screeningResult.summary`（已有）
- `initialScore`（Resume 表新字段）
- 评估维度数据（通过额外 API 调用或嵌入响应）

**方案**：在列表加载时，额外调用 `GET /api/evaluations` 获取每个简历的评估维度数据。

**优化**：批量获取 —— 修改 `GET /api/resumes` 接口，在响应中嵌入每个简历的 `evaluationDimensions` 数据。

#### 2.1.4 星级显示组件

创建 `components/resume/star-rating.tsx`：

```typescript
interface StarRatingProps {
  rating: number | null    // 1-5，null 表示未评分
  onChange?: (rating: number) => void  // 可选，有则可编辑
  size?: 'sm' | 'md'      // 默认 'sm'
  readonly?: boolean       // 默认 false
}
```

- 未评分（null）：显示 5 个灰色空星
- 已评分：显示对应数量的实心星（金色），其余为空心星（灰色）
- 可编辑时：点击星号触发 `onChange`，弹出确认（防止误触）
- `size='sm'`：列表中使用，星号较小
- `size='md'`：详情页中使用，星号较大

### 2.2 内联编辑

#### 2.2.1 交互流程

```
用户点击星级
  → 弹出小型评分浮层（Popover）
  → 显示 5 个可点击星号
  → 用户点击选择评分
  → 自动保存（调用 POST /api/evaluations）
  → 刷新该行的初筛得分
  → 关闭浮层
  → toast 提示"评分已更新"
```

#### 2.2.2 保存逻辑

```typescript
const handleRatingChange = async (resumeId: string, dimension: string, rating: number) => {
  const res = await fetch('/api/evaluations', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      resumeId,
      dimensions: [{ dimension, rating }],
      source: 'manual',
    }),
  })
  const json = await res.json()
  if (json.success) {
    // 刷新该行的初筛得分
    updateResumeScore(resumeId, json.scores.initialScore)
    toast.success('评分已更新')
  } else {
    toast.error(json.error || '保存失败')
  }
}
```

#### 2.2.3 得分刷新

保存后，API 返回 `scores.initialScore`，直接更新该行的得分显示，无需重新加载整个列表。

## 五、非功能需求

### 5.1 性能要求

- 列表加载时间 < 1s（含评估维度数据）
- 星级评分保存响应时间 < 500ms
- 得分刷新无页面闪烁

### 5.2 UI/UX 要求

- 星级评分组件使用项目统一的 UI 组件（`@/components/ui/*`）
- 使用 `sonner` toast 显示操作结果
- 评分浮层（Popover）位置合理，不遮挡其他内容
- 移动端适配：星级评分组件可正常点击
