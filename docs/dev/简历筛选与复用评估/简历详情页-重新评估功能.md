# 简历详情页 — 重新评估功能 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在已筛选简历详情页中，将「重新筛选」按钮从顶部 Header 移至评估 Tab 的职位选择器右侧，改名为「重新评估」，使其根据用户当前选中的职位执行针对该职位的 AI 评估，实现同一简历对不同职位的多次评估复用。

**Architecture:** 修改详情页 `app/resume/detail/[id]/page.tsx` 的按钮位置和逻辑，修改 `app/api/resumes/[id]/screen/route.ts` 不更新简历默认职位归属。核心服务 `ai-screener.ts` 已完整支持 `positionId` 参数，无需改动。评估完成后的显示链路（雷达图、AI分析、得分计算）已支持按职位切换，无需改动。

**Tech Stack:** Next.js 16, React 19, TypeScript, Prisma, Recharts, Tailwind CSS, shadcn/ui

## 决策汇总

| 决策点 | 选择 |
|--------|------|
| 按钮位置 | 职位选择器 Select 右侧紧跟按钮（方案 3） |
| API 行为 | 传 `selectedPositionId`，修改 API 不更新 `resume.positionId`（方案 2） |
| 按钮文本 | 动态：「开始评估」/「重新评估」/「评估中...」 |
| Header 原按钮 + AI 配置选择器 | 完全移除 |
| 按钮禁用条件 | `screening \|\| status==='SCREENING' \|\| !selectedPositionId \|\| !extractedText` |
| 评估完成 UX | 自动触发 `fetchEvaluations` 刷新雷达图和评分依据 |
| 单职位模式 | 始终显示按钮 |

- [ ] **Step 2: 修改 handleScreen — 传 positionId**

找到第 394-414 行的 `handleScreen`，改为：

```tsx
const handleScreen = async () => {
  setScreening(true)
  try {
    const payload: Record<string, string> = {}
    if (selectedPositionId) payload.positionId = selectedPositionId
    const res = await fetch(`/api/resumes/${id}/screen`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(payload),
    })
    const json = await res.json()
    if (json.error) throw new Error(json.error)
    toast.success('已提交评估，请等待处理...')
    await loadResume()
  } catch (err: unknown) {
    const msg = err instanceof Error ? err.message : '评估失败'
    toast.error(msg)
  } finally {
    setScreening(false)
  }
}
```

- [ ] **Step 3: 修改轮询回调 — 评估完成后自动刷新 evaluations**

找到第 452-466 行的轮询 `useEffect`，修改 SCREENED 回调：

```tsx
// 修改前
if (currentStatus === 'SCREENED') {
  toast.success('AI筛选完成')

// 修改后

  toast.success('评估完成')
```

- [ ] **Step 5: 在职位选择区域添加重新评估按钮**

```tsx
<Card>
  <CardContent className="p-4">
    <div className="flex items-center gap-4">
      <span className="text-sm font-medium">职位:</span>
      {positions.length > 1 ? (
        <Select
          value={selectedPositionId || ''}
          onChange={(e) => setSelectedPositionId(e.target.value || null)}
          className="w-[200px] h-9 text-sm"
        >
          <option value="">未分配职位</option>
          {positions.map((p) => (
            <option key={p.id} value={p.id}>{p.title}</option>
          ))}
        </Select>
      ) : (
        <span className="text-sm text-muted-foreground">
          {resume.position?.title || '未分配职位'}
        </span>
      )}
      <Button
        onClick={handleScreen}
        disabled={
          screening ||
          resume.status === 'SCREENING' ||
          !selectedPositionId ||
          !resume.extractedText
        }
        className="gap-2"
      >
        {screening || resume.status === 'SCREENING' ? (
          <Loader2 className="h-4 w-4 animate-spin" />
        ) : (
          <Zap className="h-4 w-4" />
        )}
        {screening || resume.status === 'SCREENING'
          ? '评估中...'
          : resume.status === 'SCREENED'
          ? '重新评估'
          : '开始评估'}
      </Button>
    </div>
  </CardContent>
</Card>
```
