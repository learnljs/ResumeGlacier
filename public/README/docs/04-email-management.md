# 四、邮件管理

> 本章介绍邮件列表与邮箱状态两个页面，用于查看收取的邮件并手动触发收取。

## 一、邮件列表

- **筛选条件**：来源（接收平台）、主题、接收时间起止、邮箱状态（已激活 / 未激活）
- **表格列**：来源（发件人 + 地址）、主题、接收时间、关联简历（姓名 + 状态徽章，点击直达简历详情）、操作
- **操作**：

| 操作 | 说明 |
|------|------|
| **生成** | 从邮件附件生成简历（单封；若邮件无附件会提示「该邮件未找到简历附件」） |
| **批量生成简历** | 勾选多封邮件后批量生成 |
| **删除** | 删除邮件记录。确认后关联简历会解除关联并保留在简历库中；若简历正在处理中，删除会被拒绝，提示稍后重试 |

## 二、邮箱状态

- 每个邮箱一张卡片，展示：**邮箱别名、地址、邮件数、简历数、上次收取时间**
- **操作按钮**：

| 操作 | 说明 |
|------|------|
| **增量获取** | 按增量方式拉取新邮件，日常推荐 |
| **全量获取** | 重新扫描整个收件箱 |

- 点击获取后，页面顶部会显示自动处理管道进度（解析队列 / 筛选队列：排队 N / 处理中 / 完成），全部完成后提示「自动管道完成：邮件收取 → 简历解析 → AI筛选 已全部完成」，可手动隐藏该提示
