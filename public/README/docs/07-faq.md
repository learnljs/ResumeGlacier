# 七、常见问题与异常处理

> 本章汇总日常使用中的常见问题、异常现象与对应的处理方法，供使用者排查参考。

## 一、简历状态异常（ERROR）

| 项目 | 内容 |
|------|------|
| **现象** | 简历详情顶部显示灰色「异常」徽章，异常信息 Tab 展示红色错误信息 |
| **处理** | 点击「重新获取」（从邮箱重新下载附件）或「重新解析」（用本地文件重解析） |
| **原因参考** | 附件解析失败、文本质量过低（如扫描件无法识别） |

## 二、邮件收取失败

- 在「邮箱状态」页面查看各邮箱上次收取时间；若长时间未更新，点击「增量获取」手动触发
- 确认邮箱配置正确（密码是否为授权码 / 客户端专用密码），可在「系统配置 → 邮箱配置」中点击「测试连接」
- 收取失败的邮件可在「邮件列表」中点击「生成」重试

## 三、AI 评估失败或未触发

- 确认已配置 AI 模型（「系统配置 → AI 模型」）且至少有一个默认模型
- 确认职位已配置评估提示词与权重模型（「系统配置 → 职位管理」）
- 确认简历已分配职位（「简历列表」中职位列为「未分配」时需手动分配或自动匹配）
- 在「简历任务」页面查看是否有失败的筛选任务

## 四、企微同步失败

- 跟进列表每行末尾显示同步状态：红叉表示同步失败，点击可「重新同步」
- 确认「系统配置 → 企微同步」中 Webhook 地址有效、字段映射配置正确
- 确认对应职位已配置企微「岗位管理」表的 record_id

## 五、找不到简历

- 使用「简历列表」的筛选条件（状态、职位、来源、日期）定位
- 邮件已收取但未生成简历时，可在「邮件列表」对该邮件点击「生成」

## 六、重要提醒

- **提示词保存即生效**，但只影响之后的新评估；修改前建议先「预览校验」用真实简历验证效果
- **「全部 AI 筛选」会覆盖已通过简历的原有结果，且不可中途取消，请谨慎使用**
- 邮箱密码、AI API Key、企微 Webhook URL 均为**加密存储**；密钥一旦丢失（如重装环境）无法解密历史数据
- 删除操作均有二次确认；删除邮件不会删除关联简历，删除任务批次不会删除关联简历
- 系统定时任务仅在生产环境运行（每 30 分钟自动收取邮件、每日 02:00 离职扫描），开发环境需手动触发
