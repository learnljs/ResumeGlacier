## 状态流转图

```
未解析 → 解析中 → 待筛选 → 筛选中 → 已评估
               ↑         ↑
        （异常为旁路）  （未分配为旁路）
```

## 状态说明

| 状态 | 说明 |
|------|------|
| **未解析** | 通过邮件收取，尚未解析 |
| **解析中** | 正在解析队列中 |
| **待筛选** | 解析完成，等待 AI 评估 |
| **未分配** | 未分配职位，不参与评估（可重新分配）；为前端根据「未分配职位」衍生的展示形态，非数据库真实状态 |
| **筛选中** | 正在筛选队列中 |
| **已评估** | 评估完成，结果按职位存储 |
| **异常** | 解析失败或文本质量过低 |

## 状态徽章配色

| 状态 | 颜色 |
|------|------|
| 未解析 | 橙 |
| 解析中 | 青 |
| 待筛选 | 黄 |
| 筛选中 | 蓝 |
| 已评估 | 绿 |
| 异常 | 灰 |
