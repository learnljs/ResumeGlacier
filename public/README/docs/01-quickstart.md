## 一、这个系统解决什么问题

传统招聘里，HR 的大量时间花在「收简历、初筛、跟进度」这些重复劳动上：

- **简历散落在邮箱**：手动下载、重命名、归档，容易遗漏也难检索。
- **初筛靠人工逐份看**：慢，而且不同人标准不一致，难以横向比较。
- **跟进靠表格 / 脑子记**：电话、面试、offer 多头推进，状态一多就漏。
- **渠道杂、来源乱**：社招、内推、猎头邮件混在一起，难区分质量。
- **多人协作没有边界**：谁在看、谁在跟、权限如何划分，说不清。

本系统把这条链路自动化、结构化：

- **自动收取**：对接企业邮箱 IMAP，定时拉取简历邮件并解析附件，结构化入库。
- **AI 智能筛选**：按职位要求自动评估，给出「冰山模型」六维分析与匹配度，初筛标准化。
- **跟进状态机**：从联系到入职的全流程状态化、可追溯，不再靠记忆。
- **来源与复用**：来源匹配规则区分渠道；简历复用评估支持跨职位批量挑人。
- **登录与权限**：管理员与人员账号分离，操作有边界（见系统配置 · 人员管理）。

## 二、页面导览：每个页面能干什么

> 左侧主导航即系统的功能分区，下表按「你会在什么场景下用它」逐一说明。

### 主导航（顶级页面）

| 页面 | 路径 | 主要用途 |
|------|------|----------|
| 数据概览 | `/resume/dashboard` | 全局仪表盘：收取总量、各状态分布、跟进漏斗、职位维度概览，一眼掌握招聘全局。 |
| 系统配置 | `/resume/system-config` | 系统初始化与管理中枢，含邮箱、AI 模型、职位、来源、提示词、Webhook、人员管理等子页（详见 [六、系统配置](./06-system-config/README.md)）。 |
| 招聘中心 · 简历列表 | `/resume/list` | 所有自动收取的简历，支持查看、搜索、进入详情。 |
| 招聘中心 · 已筛选简历 | `/resume/screened` | AI 评估结果汇总，在此决定「跟进」或「不合适」。 |
| 招聘中心 · 简历复用评估 | `/resume/reevaluate` | 跨职位批量重新评估已有简历，快速挑人。 |
| 招聘中心 · 跟进管理 | `/resume/follow-up` | 跟进全流程状态机：联系 → 面试 → offer → 入职，可追溯。 |
| 任务管理 | `/resume/task-batches` | 手动 / 批量任务，如手动获取邮件、批量重评等。 |
| 系统介绍 | `/resume/about` | 本文档，系统使用说明总入口。 |

### 系统配置子页

- **邮箱** `/resume/system-config/email`：配置企业邮箱 IMAP 并测试连接，是简历自动收取的来源。
- **AI 模型** `/resume/system-config/ai`：添加一个 OpenAI 兼容的 AI 模型，用于简历评估。
- **职位** `/resume/system-config/positions`：创建 / 管理招聘职位，设置职位要求、评估权重与提示词。
- **简历来源** `/resume/system-config/sources`：设置来源名称与邮件主题匹配规则，区分渠道。
- **提示词** `/resume/system-config/prompts`：管理评估 / 提取用的提示词版本。
- **Webhook** `/resume/system-config/webhooks`：配置企微智能表格等外部同步。
- **人员管理** `/resume/system-config/staff`：管理员与登录账号管理（登录鉴权与权限）。

### 其他页面

- **简历详情** `/resume/detail/[id]`：单份简历的解析内容、AI 评估、历史与操作，从「简历列表」或「已筛选简历」点入。

## 三、首次使用：初始化清单

系统第一次跑起来后，需由管理员完成基础配置（详见 [六、系统配置](./06-system-config/README.md)）：

- **配置邮箱**：添加企业邮箱 IMAP 设置并测试连接（企微邮箱、QQ 邮箱等均可）。
- **配置 AI 模型**：添加一个 OpenAI 兼容的 AI 模型，用于简历筛选评估。
- **创建职位**：创建招聘职位，填写职位描述与筛选要求，配置评估权重与提示词。
- **（可选）配置简历来源**：设置来源名称与邮件主题匹配规则，便于区分渠道。
- **（可选）配置企微同步**：设置企业微信智能表格的 Webhook 与字段映射。
- **（可选）人员管理**：在「系统配置 · 人员管理」创建登录账号，分配权限。

## 四、日常操作主线

配置完成后，HR 的日常工作是一条很顺的线：

1. **收取简历**：生产环境每 30 分钟自动收取；也可在邮箱 / 任务页手动「增量获取」「手动获取」。
2. **自动处理**：系统自动解析、匹配职位、AI 评估，无需人工干预。
3. **处理结果**：在「已筛选简历」看评估，合适的点「跟进」，不合适的点「不合适」。
4. **推进跟进**：在「跟进管理」按状态机推进：电话 / 微信联系 → 预约面试 → 面试结束 → 发 offer → 入职。
5. **跨职位挑人**：需要时到「简历复用评估」跨职位批量评估已有简历。
