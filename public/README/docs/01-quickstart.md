## 一、基础配置

首次使用系统前，需要由管理员完成以下基础配置（详见 [六、系统配置](./06-system-config/README.md)）：

- **配置邮箱**：添加企业邮箱的 IMAP 设置并测试连接（企微邮箱、QQ 邮箱等均可）
- **配置 AI 模型**：添加一个 OpenAI 兼容的 AI 模型，用于简历筛选评估
- **创建职位**：创建招聘职位，填写职位描述与筛选要求，配置评估权重与提示词
- **（可选）配置简历来源**：设置来源名称与邮件主题匹配规则，便于区分渠道
- **（可选）配置企微同步**：设置企业微信智能表格的 Webhook 与字段映射

## 二、日常操作主线

完成配置后，HR 的日常操作非常简单：

1. **收取简历**：简历会自动收取（生产环境每 30 分钟自动收取一次），也可以在「邮箱状态」页面点击「增量获取」，或在「简历任务」页面点击「手动获取」手动收取
2. **自动处理**：系统自动解析简历、自动匹配职位、自动进行 AI 评估，无需人工干预
3. **处理评估结果**：在「已筛选简历」页面查看评估结果，对合适的候选人点击「跟进」，对不合适的候选人直接点击「不合适」
4. **推进跟进**：在「跟进管理」页面按流程推进：电话或微信联系 → 预约面试 → 面试结束 → 发 offer → 入职……
5. **跨职位挑人**：需要挑人时可使用「简历复用评估」跨职位批量评估已有简历
