# 三、招聘中心（组内总览）

> 招聘中心是日常招聘业务操作的主阵地，共 5 个页面（侧边栏导航 4 个入口 + 简历详情子页）。本章按「查看 → 评估 → 筛选 → 跟进」的业务顺序组织。

## 页面分工

| 页面 | 定位 | 入口 |
|------|------|------|
| **简历列表** | 系统收取的所有简历，处理分配职位与批量操作 | [01 · 简历列表](./01-resume-list.md) |
| **简历详情** | 单个候选人的完整信息与 AI 评估结果 | [02 · 简历详情](./02-resume-detail.md) |
| **已筛选简历** | 已完成 AI 评估、等待 HR 决策的简历 | [03 · 已筛选简历](./03-screened-resumes.md) |
| **简历复用评估** | 按新职位跨职位批量复用评估已有简历 | [04 · 简历复用评估](./04-resume-reuse.md) |
| **跟进管理** | 候选人从沟通到入职（或淘汰）的全过程（系统最核心模块） | [05 · 跟进管理](./05-follow-up.md) |

## 典型业务流

```
简历列表（收取/解析/分配职位）
    ↓ AI 自动评估
已筛选简历（查看评分 → 跟进 / 不合适）
    ↓
跟进管理（沟通中 → 待面试 → 已面试 → 发offer → 待入职 → 已入职）
    ↑
简历详情（任意环节查看候选人完整信息与评估依据）
```

| 需要 | 去哪个页面 |
|------|-----------|
| 查看系统收了多少简历、是否解析 / 分配职位 | 简历列表 |
| 查看某候选人完整信息、AI 评估依据 | 简历详情 |
| 处理 AI 评估结果（跟进 / 淘汰） | 已筛选简历 |
| 用新职位挑已有简历库里的人 | 简历复用评估 |
| 管理面试、offer、入职全流程 | 跟进管理 |
