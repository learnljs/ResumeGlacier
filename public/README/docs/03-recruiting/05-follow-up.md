# 招聘中心 · 05 跟进管理（核心）

> 「跟进管理」是系统最核心的模块，用于管理候选人从沟通到入职（或淘汰）的全过程。

## 一、页面结构

- **顶部**：沟通中 / 待面试 / 已面试 3 组计数 + 「导出」「刷新」按钮
- **10 个状态页签**：沟通中、待面试、已面试、已发offer、待入职、已入职、已离职、不合适、拒offer、取消面试
- 筛选区与数据表格、分页

## 二、筛选条件

- **关键词**：姓名 / 邮箱 / 电话（回车即搜索）
- **高级筛选**：

| 条件 | 说明 |
|------|------|
| 标签 | 按分类分组多选，可选择「满足任一」或「满足全部」 |
| 职位 | 多选 |
| 跟进时间起止 | 时间范围 |
| 联系结果 | 未尝试 / 已联系上 / 未联系上（仅「沟通中」页签显示） |

- **排序**：按进入当前状态的时间升 / 降序切换

## 三、表格列说明（随页签变化）

| 列 | 说明 |
|----|------|
| **候选人** | 姓名 + 电话，点击进入详情；双击行可打开跟进日志 |
| **评分** | 沟通中页签显示知识 / 技能星级与得分；待面试、已面试页签显示 6 维度星级与得分 |
| **面试时间** | 在待面试页签可直接内联修改 |
| **标签** | 最多显示 3 个，带编辑按钮，优先显示人为添加的 |
| **职位** | 关联职位 |
| **联系结果** | 未尝试 / 已联系上 / 未联系上 |
| **备注** | 悬停看全文、点击可编辑 |
| **同步状态** | 绿勾 = 已同步到企微（悬停看时间）、红叉 = 同步失败（点击可重新同步）、灰圈 = 未同步 |

## 四、各状态可执行的操作

| 当前状态 | 可执行操作 |
|----------|-----------|
| 沟通中 | 预约面试、不合适、取消跟进 |
| 待面试 | 面试结束、取消面试、回退 |
| 已面试 | 发 offer、不合适、回退 |
| 已发 offer | 接受 offer、拒 offer、回退 |
| 待入职 | 入职、拒 offer、回退 |
| 已入职 | 离职、回退 |
| 已离职 / 拒offer / 取消面试 / 不合适 | 仅回退 |

## 五、跟进状态机说明

### 正向流转（括号内为该操作必填字段）

- 沟通中 → 待面试（面试时间）、沟通中 → 不合适（原因）
- 待面试 → 已面试、待面试 → 取消面试（原因）
- 已面试 → 已发offer（入职时间）、已面试 → 不合适（原因）
- 已发offer → 待入职（入职时间）、已发offer → 拒offer（原因）
- 待入职 → 已入职（入职时间）、待入职 → 拒offer（原因）
- 已入职 → 已离职（离职日期 + 离职原因）

### 回退路径（需填写回退原因，写入审计日志）

- 待面试 → 沟通中
- 已面试 → 待面试
- 已发offer → 已面试
- 待入职 → 已发offer
- 已入职 → 待入职
- 已离职 → 已入职
- 拒offer → 待入职 / 已发offer
- 取消面试 → 待面试
- 不合适 → 已面试 / 沟通中

> 速查表见 [附录 A · 跟进状态机速查表](../08-appendix/01-follow-up-state-machine.md)

## 六、常用弹窗 / 抽屉

| 弹窗 / 抽屉 | 说明 |
|-------------|------|
| **预约面试** | 选择面试时间后确认 |
| **不合适 / 取消面试 / 拒offer（共用窗口）** | 提供 15 条常用预设原因一键填入（拒销、已有工作、无b端经验、无销售经验、工作年限>5、学历不符、薪资不满意、拒面、临时有事、重复、外国、一面淘汰、二面淘汰、拒offer、联系不上（2次）），原因必填 |
| **录取 / 入职** | 选择入职时间 |
| **离职** | 填写离职日期与原因（必填） |
| **面试结束** | 进行 6 维度评分（分「水面之上 / 水面之下」两组）、选择标签、填写面评备注 |
| **回退** | 选择目标状态并填写回退原因（必填） |
| **跟进日志** | 从右侧滑出的抽屉，按时间线展示该候选人的全部操作日志（创建、状态变更、标签、备注等） |
| **导出** | 勾选要导出的字段（姓名、手机号、拒绝原因、初筛得分、综合得分、面试时间、标签、备注、联系结果、职位、接收时间、跟进时间等 13 项），下载 CSV 文件，导出的数据为当前选择的这个 tab 的列表数据 |
| **编辑备注、编辑原因** | 带预设的快捷编辑窗口 |

## 七、企业微信同步

- 跟进记录进入「待面试」及之后阶段后，**自动同步到企业微信智能表格**（进入待面试为新增，之后变更为更新）
- 同步内容按「系统配置 → 企微同步」中的字段映射全量转换推送
- 每行末尾的同步状态图标可直观查看：绿勾已同步 / 红叉失败（点击重新同步）/ 灰圈未同步
- 每日凌晨 **02:00** 系统自动扫描当日到期的离职记录，自动转为「已离职」并触发企微同步
