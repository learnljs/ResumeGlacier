# 招聘中心 · 01 简历列表

> 「简历列表」用于查看系统收取的所有简历，是日常招聘的起点：查看、分配职位、批量处理都在这里完成。

## 一、页面结构

页面顶部为 Tab 栏，三个 Tab 各自独立记忆筛选条件：

| Tab | 说明 |
|-----|------|
| **所有** | 全部简历 |
| **未分配** | 尚未分配职位的简历，通常为新增职位尚未在系统内完成配置所致 |
| **异常** | 解析失败或文本质量过低的简历 |

## 二、筛选条件

- **关键词**：按候选人姓名搜索（支持输入法），可以是昵称（邮件上面的称呼）
- **日期范围**：选择起始与结束日期
- **状态**：全部状态 / 待筛选 / 筛选中 / 已评估（仅「所有」Tab 显示）
- **职位**：选择指定职位
- **来源**：按简历来源渠道筛选（如 BOSS直聘、前程无忧等）
- **邮箱**：按收件邮箱筛选

## 三、表格列说明

| 列 | 说明 |
|----|------|
| **候选人** | 姓名，可一键复制；点击「查看」进入详情 |
| **来源 / 邮箱** | 简历来源徽章、邮箱来源 |
| **职位** | 已分配职位徽章；未分配显示「未分配」 |
| **评分** | 初始评分，按分数着色：≥80 绿色 / ≥60 蓝色 / ≥30 黄色 / <30 红色 |
| **接收时间** | 点击表头可按升序或降序排序 |
| **筛选时间** | 点击表头可按升序或降序排序 |

## 四、常用操作

| 操作 | 说明 |
|------|------|
| **自动匹配职位** | 在职位列点击闪电图标，系统按职位关键词自动匹配职位 |
| **手动分配职位** | 在职位列下拉选择目标职位 |
| **查看详情** | 点击「查看」按钮或双击该行 |
| **批量匹配职位** | 勾选多份简历后，顶部出现「批量匹配职位(N)」按钮 |
| **批量解析** | 勾选后点击「批量解析(N)」，对未解析简历执行解析 |
| **批量 AI 筛选** | 勾选后点击「批量AI筛选(N)」，对选中简历执行 AI 评估 |
| **全部 AI 筛选** | 点击顶部「全部AI筛选」，对所有待筛选简历发起评估。点击后需确认——该操作会覆盖已通过简历的原有结果，且不可中途取消，**谨慎操作！** |

批量操作完成后，页面会以提示消息反馈结果，如「已提交 N 份简历到筛选队列」「已匹配到职位：XX」。
