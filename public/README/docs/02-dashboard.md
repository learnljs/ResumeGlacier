# 二、数据概览

> 「数据概览」是系统首页，用于掌握整体招聘数据，包括统计卡片、趋势图表与跟进看板三大部分。

---

## 一、统计卡片

页面顶部展示 4 张统计卡片：

- 本日收取
- 本周收取
- 本月收取
- 总简历数

页面顶部同时显示已配置的邮箱列表；若尚未配置邮箱，会提示「尚未配置邮箱」。

## 二、趋势图表

页面中部展示 3 组图表：

| 图表 | 说明 |
|------|------|
| **收取趋势图** | 简历收取量随时间的变化趋势 |
| **岗位趋势对比** | 选择多个职位（可全选），在同一图表中对比各职位的简历趋势；支持日 / 周 / 月粒度切换和时间范围选择 |
| **曝光卡占比趋势** | 选择多个职位（可全选），在同一图表中展示 Boss 直聘曝光刷新卡相关简历的占比变化 |

## 三、跟进看板

页面底部为跟进看板，用于快速了解当前跟进进展：

- **筛选条件**：顶部可选择岗位（多选，默认全部岗位）与投递时间段（支持手动输入起止日期，也可快捷选择周 / 月，默认本周）
- **状态卡**：看板展示 10 个跟进状态卡（沟通中、待面试、已面试、已发offer、待入职、已入职、已离职、不合适、拒offer、取消面试），显示所选范围内当前处于各状态的人数
- **联系结果环形图**：未尝试 / 已联系上 / 未联系上
- **状态流转图**：展示跟进管理中各状态间的简历流转数量
