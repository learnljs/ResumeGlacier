# 五、任务管理 · 简历任务

> 「简历任务」用于查看邮件收取与简历处理的批次进度。

## 一、页面概览

- **顶部统计**：已完成批次 / 处理中批次 / 异常总数 / 总简历数
- **顶部按钮**：「刷新」「手动获取」（手动触发邮件收取）

## 二、批次卡片（页面每 3 秒自动刷新）

- **批次编号**（格式 `YYYYMMDD-NNN`）+ **类型徽章**（获取任务蓝 / 解析任务橙 / 筛选任务紫）+ **状态**（进行中 / 已完成）+ **来源说明**（定时任务 / 手动获取 / 批量解析 / 重新筛选）+ **关联邮箱**
- **双进度条**：解析进度、筛选进度，带已完成 / 总数计数
- **状态行**：开始时间、解析中 N、失败 N、筛选中 N、异常 N

## 三、批次操作

| 操作 | 说明 |
|------|------|
| **停止** | 仅进行中的批次可停止（确认后处理中的简历会重置为初始状态） |
| **删除** | 仅已完成批次可删除（确认后关联简历不会被删除，只解除关联） |
| **展开** | 点击卡片展开详情，按批次类型展示统计卡（如获取任务：解析成功 / 失败、筛选通过 / 异常），并列出解析失败的简历（前 5 条，含错误信息） |
