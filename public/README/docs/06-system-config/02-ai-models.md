## 一、新增 / 编辑模型表单字段

| 字段 | 说明 |
|------|------|
| 配置别名 | 选填，留空自动生成为「服务商 + 模型」 |
| AI 服务商 | OpenAI / DeepSeek / 通义千问 / 智谱 AI / 自定义；点选自动填充 Base URL 与模型 |
| API Base URL | 选填，留空使用 OpenAI 官方地址；手动修改后变为「自定义」 |
| 模型名称 | 必填，可从预设下拉选择或手动输入 |
| API Key | 必填（密码框）；编辑时留空则不修改 |
| 用途 | 多选：简历筛选 / 结构化提取 / 视觉 OCR / 头像识别 |
| 设为默认模型 | 勾选后 AI 筛选时优先使用 |

## 二、操作

- **表单操作**：测试连接、保存、取消
- **列表操作**：设默认（星标）、编辑、删除（带确认）
- **列表展示**：别名、默认 / 已禁用徽章、服务商、模型、URL、使用次数（X 次筛选）、用途标签

## 三、注意事项

- 第一个新建的模型会自动设为默认模型；建议至少保留一个默认模型
- 密钥仅展示使用次数，不展示密钥内容
