# 系统配置 · 06 跟进标签

> 用途：管理跟进标签。标签分为 3 大分类：硬性标签（蓝色）、意向判断（黄色）、自定义（灰色）。

## 一、新增标签

- 填写名称（回车可添加）
- 选择颜色（默认 `#3b82f6`）
- 选择分类（硬性标签 / 意向判断 / 自定义）
- 点击「添加」

## 二、标签展示

- 来源图标（AI 自动 / HR 手动）、颜色点、名称、引用次数
- 悬停出现编辑（改名称 / 颜色）与删除按钮
- **AI 来源标签带「AI」徽章，不可手动删除**（重新筛选时会自动清理）
