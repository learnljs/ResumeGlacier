## 一、职位列表页

- 顶部「已停用职位」「新增职位」按钮
- 卡片列表展示：职位名、部门徽章、简历数、描述（两行截断）、筛选要求前 100 字
- 点击卡片进入详情

## 二、职位详情 / 编辑页

- **顶栏**：返回、职位名、状态徽章（启用中 / 已停用）、简历数、「有未保存的修改」提示
- **状态操作**：
  - 停用（确认后提示：停用后职位与权重模型不可修改，已关联简历不受影响）
  - 启用
  - 删除（若有关联简历，删除按钮禁用并提示「该职位关联了 X 条简历，无法删除」；可删除时需确认，会连带删除权重模型）
- **基本信息表单**：职位名称（必填）、所属部门、职位描述、筛选要求（必填，AI 据此打分）、邮件匹配关键词（逗号分隔，系统据此自动匹配邮件到职位）。保存按钮显示「已保存 / 保存修改 / 保存中」状态
- **权重模型管理**：
  - 分两组：「初筛模型」（仅知识、技能 2 维度）与「冰山模型」（全部 6 维度）
  - 新增模型：填写模型名称、各维度权重（数字输入 + 滑块），权重总和须恰好为 100%（实时显示红 / 绿点与差额提示）
  - 模型卡片操作：设默认（星标，默认模型不可删除）、编辑（改名称 + 拖动滑块调整权重，保存前校验总和 100%）、删除（默认模型不可删除）
  - 卡片内以进度条直观展示各维度占比，标注「冰山之上 / 冰山之下」

## 三、新建职位页

- 填写基本信息保存后跳转详情页
- 创建职位后将自动生成默认的初筛和冰山权重模型（初筛 50/50；冰山 15/15/20/20/15/15）

## 四、已停用职位页

- 列表展示停用职位（卡片半透明），每条有「启用」「删除」按钮
- 删除仅当该职位有 0 份简历时可用，确认提示「永久删除不可撤销」
