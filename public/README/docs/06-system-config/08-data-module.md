## 一、数据库结构（左侧树）

- 可搜索表名或字段、全部展开 / 折叠
- 展开查看字段名、类型、注释

## 二、查询区（右侧）

- **多标签页**：可新建 / 重命名 / 关闭，自动保存在浏览器本地
- **SQL 编辑框**：支持 `Cmd/Ctrl + Enter` 执行；「运行」「清空」「导出」按钮

## 三、结果区

- 分页表格（每页 10 / 20 / 50 / 100 条），顶部显示记录数
- 「导出」下载 CSV（BOM 编码，Excel 友好）
- SQL 错误以红框显示

## 四、保存 / 加载

- 「保存 / 加载」：可命名保存常用查询（同名覆盖，存浏览器本地，清除浏览器数据会丢失）
- 加载时可选「打开」覆盖当前页或「新标签」打开，也可删除
